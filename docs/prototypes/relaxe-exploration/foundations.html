SELECTED DESIGN DIRECTION

Consistent styling, adaptable color.

Keep the theme choices

Use the existing light, dark and AMOLED themes. When Material You is enabled, resolved system/wallpaper colors feed the same components. A's neutral and B's warm palettes remain fallback examples, with no fixed shipping default chosen.

Map each role

Canvas, post cards, read titles, comment text, toolbar, navigation, links and vote feedback keep their own theme roles. A custom icon or read-post color should survive a new component. Media retains a readable dark control layer.

Keep the selected form

A's system typography, B's moderate corners and C's solid icon treatment apply across every example. The studies use 12px card/control corners and 24px sheets as reference values, with at least 48px action targets. Native geometry remains to be refined.
